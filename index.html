Ränge kaufen mit dem Geld, das du bereits im Spiel hast. Kein Echtgeld, keine Wartezeit — der Rang ist sofort da.

  1. Schritt 1

    Code holen

    Gib im Spiel /linkweb ein. Du bekommst einen 6-stelligen Code, 5 Minuten gültig.

  2. Schritt 2

    Account verknüpfen

    Trag den Code oben bei „Account verknüpfen" ein. Danach siehst du dein echtes Ingame-Guthaben.

  3. Schritt 3

    Rang kaufen

    Das Guthaben wird direkt über Vault/EssentialsX abgezogen, LuckPerms setzt den Rang sofort.
